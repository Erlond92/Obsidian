
## Постоянные переменные

`final` - объявление константы

`const` - константы

Разница только в том, что `const` получает значение при компиляции, а `final` при запуске приложение

## Объявление переменных

`var` - объявление переменных 

`Переменная.runtimeType` - тип переменной

## `null`

`int n = int.tryParse('werg')`

`r!` - не проходит проверку на null

`r ?? n` - если r = null, то выводит n, и наоборот

`int?` - проверка на null
